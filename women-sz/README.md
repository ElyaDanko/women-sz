## Как опубликовать сайт бесплатно — 5 шагов (GitHub Pages)

**Шаг 1. Подключите форму.** Зарегистрируйтесь на [formspree.io](https://formspree.io), нажмите **New form**, укажите почту для заявок. Скопируйте ID формы (8 символов из адреса вида `https://formspree.io/f/xabcdefg`). Откройте `index.html` в любом текстовом редакторе, найдите `YOUR_FORM_ID` и замените на свой ID. Бесплатный тариф — 50 заявок в месяц.

**Шаг 2. Установите git** (на этом Mac его пока нет). В Терминале:

```bash
xcode-select --install
```

Появится окно — нажмите «Установить» и подождите 5–10 минут.

**Шаг 3. Создайте репозиторий.** Зайдите на [github.com/new](https://github.com/new) (если аккаунта нет — сначала зарегистрируйтесь), назовите репозиторий `women-sz`, выберите **Public**, больше ничего не отмечайте, нажмите **Create repository**.

**Шаг 4. Загрузите файлы.** В Терминале перейдите в папку с сайтом и выполните команды (замените `ВАШ_ЛОГИН` на логин GitHub):

```bash
cd путь/к/папке/women-sz
git init -b main
git add index.html
git commit -m "Сайт клуба"
git remote add origin https://github.com/ВАШ_ЛОГИН/women-sz.git
git push -u origin main
```

При первом `push` GitHub попросит войти — откроется окно браузера.

**Шаг 5. Включите Pages.** В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save**. Через 1–2 минуты сайт откроется по адресу:

```
https://ВАШ_ЛОГИН.github.io/women-sz/
```

Эту ссылку ставьте в шапку Instagram и в закреп Telegram.

### Как обновлять сайт

Поправили `index.html` — выполните в папке:

```bash
git add index.html && git commit -m "Обновили события" && git push
```

### Вариант совсем без команд

Откройте [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите туда папку `women-sz` — сайт опубликуется сразу. Для Vercel нужен Node.js: `npx vercel --prod` в папке сайта.

## Что менять в `index.html`

- **Ближайшие события** — в самом низу файла блок `СОБЫТИЯ — МЕНЯТЬ ЗДЕСЬ`: список из блоков `{ date, time, title, text, facts }`. Скопировали блок — добавили событие, удалили — убрали. Если список пуст, сайт сам покажет «Готовим новый анонс».
- **Фото прошедших встреч** — создайте рядом с `index.html` папку `photos`, положите туда фото и у нужной карточки замените `class="poster p-box"` на `class="poster has-photo" style="background-image:url('photos/boxing.jpg')"`. Не забудьте добавить папку в git: `git add photos`.
- **Тексты** — обычный текст между тегами, ищите по словам через Cmd+F.

## Важно про доступность в Китае

- `github.io` в Китае без VPN открывается нестабильно, `vercel.app` и `netlify.app` — тоже с перебоями. Ваша аудитория сидит в Instagram и Telegram, то есть VPN у неё есть, — для старта этого достаточно.
- Шрифты подгружаются с Google Fonts, но не блокируют страницу: без VPN сайт просто откроется со стандартными шрифтами телефона.
- Formspree без VPN тоже может не отправить заявку — на этот случай форма показывает ссылку на Telegram.
- Если захотите, чтобы сайт открывался у всех без VPN, — следующий шаг это свой домен и хостинг в Гонконге.
